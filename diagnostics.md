# Воспроизведение и исправление ошибок

Команды выполняются в PowerShell на Windows. Работайте только с этим учебным сайтом и отдельной копией Tomcat.

1. 404: при запущенном сервере переименовать `src\main\webapp\index.html` в index.html.bak, запросить
   /my-site/index.html. В Network браузера будет 404. Вернуть имя и обновить страницу: 200.
2. CSS: удалить разделительную закрывающую скобку между первым и вторым правилом styles.css, посмотреть изменение стилей
   и файл во вкладке Sources. Вернуть скобку. Браузер восстанавливает CSS после некоторых ошибок, поэтому пропажа всех
   стилей не гарантируется.
3. Конфигурация: скопировать server.xml.example в `conf\server.xml` отдельного установленного Tomcat, заменить порт 8080
   на 99999. Из папки установленного Tomcat запустить `.\bin\catalina.bat run`. Прочитать ошибку порта в консоли/logs,
   вернуть 8080 и запустить повторно. Для встроенного режима эквивалент: `.\mvnw.cmd exec:java "-Dport=99999"`; затем
   `.\mvnw.cmd exec:java "-Dport=8080"` из папки проекта.

На странице приведена краткая учебная биография без вымышленных личных фактов. При желании ученик может дополнить её
собственными интересами.
